## Getting Started

### Prerequisites

- Go 1.21 or higher
- Zed editor (recommended)

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd SurfaceIntel
   ```

2. Run the application:
   ```bash
   go run main.go
   ```

3. Build the binary:
   ```bash
   go build -o surfaceintel main.go
   ```
